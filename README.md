# S4BBIR — Creative Developer Portfolio

Immersive personal portfolio built with Next.js, Three.js, GSAP, and Lenis.

## Stack

- **Next.js 16** (App Router)
- **React Three Fiber** + **Three.js** — WebGL hero environment
- **GSAP** + **ScrollTrigger** — cinematic scroll animations
- **Lenis** — smooth scrolling
- **Tailwind CSS v4** — styling
- **TypeScript** — type safety


## Configuration

All personal info, projects, and social links live in:

- `src/config/site.ts` — identity, navigation, education
- `src/config/projects.ts` — projects, skills, lab experiments

Replace placeholder values marked with `[ADD ...]` with your actual URLs and descriptions.

## Project Images

Place optimized WebP/AVIF images in `public/projects/` and update paths in `src/config/projects.ts`.

## Build

```bash
npm run build
npm start
```
